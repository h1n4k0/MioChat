# 配套服务端升级与首次登录

本说明适用于本仓库的配套服务端与原生客户端候选，不代表已经部署或完成整体验证。
当前已知失败与未验证范围见 [验证状态](VALIDATION_STATUS.md)。

## 用户正常首用

1. 正常启动 GPUI 客户端，只自动尝试一次 `chat.mio.blue:22`。
2. SSH 传输采用匿名 keyboard-interactive 握手，不把应用用户名/密码当成 SSH
   或操作系统登录凭据。首次未知主机密钥必须核对指纹并明确信任；变更的主机密钥
   不得绕过验证。设备私钥不是普通应用密码登录的前提。
3. 只有当前连接收到兼容的 `miochat-gui-v1` 协议 hello 后才开放应用登录提交。
   用户明确点击登录或按新的 Enter 事件提交；未就绪时不排队密码，不因重连、
   迟到响应或重复按住按键自动重送。失败可重试或打开高级设置。
4. 高级设置才显示服务器、端口、SSH 用户和可选设备密钥。进入/退出高级设置
   取消旧连接代次并清除密码、确认密码、邀请码和临时密钥口令。账户不是 SSH 用户。
5. `--mock` 和 `--fixture-driver` 保持显式本地模式，不启动公共服务器连接。

线上普通 TUI 可以工作，不代表线上服务器已有 GUI 子系统。未升级的服务器若
拒绝 subsystem，本客户端应明确报错，不假登录、不回退为终端画面包壳。
此前真实连接观察为 SSH 匿名握手成功但 subsystem 被拒绝；这不是本候选的新部署验证。

## 管理员兼容前提（本说明不授权执行）

- 使用本次**配套源码构建的服务端**，同一 SSH listener 同时保留普通 shell+PTY
  与 `miochat-gui-v1` subsystem。不是任意上游版本更新都能提供新协议。
- 保留原监听地址/端口、服务用户、状态目录权限、SSH 主机密钥和应用账户数据。
  反向代理/SSH 网关必须实际转发 subsystem 请求，不能仅支持交互 shell。
- 服务端依旧支持标准 SSH+PTY 的应用登录、聊天与原命令；新客户端附件等通过
  协商能力启用。旧 TUI 不因此获得原生图片解码界面，附件可以显示文本占位。
- Go 构建版本见 `go.mod`；原生客户端版本与平台要求见 `gpui-client/README.md`。
  默认 Linux 无显示后端的测试产物不是 Windows 可执行文件。
- dot 默认关闭。继承管道/适配代码和私有审阅 UI 不等于已配置真实 OAuth、host
  订阅或真实助手发送；这些另行部署授权。

## 数据库、备份与回滚

**当前 schemaVersion=7。启动以及 `-check` 都会经过 openStore/migrate；
`-check` 不是只读检查，不可直接拿生产状态目录试运行新二进制。**

升级前由管理员在维护窗口停止旧 writer，按现有备份流程取得一致性数据库备份，
同时保留完整状态目录（含 `host_ed25519`）、旧二进制及服务配置，并验证备份
确实可恢复。不要只在写入中的 SQLite 上复制主 `.db` 而丢 WAL。

先在独立状态目录副本验证升级、旧 SSH+PTY 登录/聊天/命令和 GUI 登录/双向消息。
迁移代码会为已有旧版本建立 pre-v* 数据库快照，但它不替代完整外部备份或恢复演练。
未知更高 schema 会拒绝打开；迁移成功也不证明生产兼容已验。

回滚需要停止新进程，保留失败现场，换回旧二进制并恢复升级前的**完整一致性状态**。
不要用旧程序直接降级打开迁移后的数据库。升级后新增数据需另行导出/对账；不能
承诺回滚仍保留所有新增数据，不能凭新文件名覆盖生产库。

## 附件与容量

- 服务端按稳定账号 UID 跨房间/会话原子计量：每日 100,000,000 字节，单件
  20,000,000 字节；本候选采用北京时间 00:00 重置和十进制单位。
- 计量是已接受源字节加未接收预留；取消/失败不退已接收部分，仅释放剩余预留。
  引用已上传图片不重复计上传额度。图片/自定义图片表情同计；不是按文件扩展名绕限。
- 原图字节保留，可能包含 EXIF；预览、大小和摘要绑定同一发布字节。
  PDF 是签名检查后显式下载，不是安全扫描。没有任意外链自动抓取或执行。
- SQLite 保存分块 BLOB 和引用；日额度不是服务器总磁盘上限。应另监控 DB/WAL、
  备份和可用容量。过期上传清理有界且活动驱动，删除行使 SQLite 页可复用，
  不自动 VACUUM，不保证操作系统立即释放文件大小。
- 撤回会拒绝后续服务器读取，不可能抹除已下载文件；不宣称跨房间所有既有预览
  即时失效。UNKNOWN 应查原操作标识，不能自动重发或重复计费。

## 自动化与发布门

新回归 `TestPairedServerLegacyPTYAndGUIApplicationLogin` 必须在**同一个真实
loopback SSH 服务实例**完成旧 PTY 既有账号登录、原命令、与 GUI 子系统双向消息，
并拒绝 GUI 应用登录前发送。原认证、迁移、附件、配额、权限和命令回归不可省略。
Rust 应验证首次连接/hello/Advanced/秘密清理/陈旧回调及本地预览边界，并编译真实主路由。

自动化结果以本 PR 精确提交的验证清单为准；旧包记录、原失败和诊断结果单独保留，
不能替代当前发布源的结果。真实 Windows GUI/IME、线上兼容、管理员备份恢复与生产部署均未执行。
本候选仍有真实回归失败，见 [当前验证状态](VALIDATION_STATUS.md)。经明确授权可先提交
**诊断性 draft PR** 供独立 CI 验证；这不表示云端完成、可发布或可部署。
